Key Design Decisions

  • eventId as Kafka message key — ensures partition affinity and ordering per event; supports idempotency check in consumer
  • acks=all + enable.idempotence=true — exactly-once delivery guarantee to the broker
  • ack-mode=MANUAL_IMMEDIATE — offsets committed only after explicit acknowledge(); prevents message loss on consumer restart
  • DLQ always acknowledged — both business failures and system errors commit the offset to avoid infinite retry on poison-pill messages
  • GET endpoints bypass Kafka — reads remain synchronous and low-latency (no Kafka involved)
  • Separate DLQ container factory — uses LinkedHashMap as value type to avoid class-cast errors from EventRequest deserializer
  • MockBean in controller tests — keeps unit tests fast and deterministic without requiring a broker
  • @EmbeddedKafka in integration tests — validates true round-trip behaviour without external infrastructure
